# 🎁 PostDeliveryBonus — Follow-up после выдачи

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

**Автор:** yungspider

Через N минут после автовыдачи покупатель получает вежливое follow-up сообщение:
всё ли в порядке, просьба оставить отзыв и бонус для постоянных покупателей.
Больше отзывов → выше рейтинг → больше продаж.

## Возможности

- 🎁 **Авто-сообщение после выдачи** — не мгновенно (это выглядит как спам),
  а через настраиваемую задержку (по умолчанию 60 минут, диапазон 5 мин — 3 суток),
  когда покупатель успел проверить товар.
- 📝 **Шаблон с переменными**: `$username` (ник покупателя), `$lot` (название лота),
  `$order` (номер заказа). Редактируется в меню.
- 📮 **Очередь отложенных сообщений хранится на диске** — переживает рестарт
  Кардинала, ничего не потеряется.
- Каждому заказу — **не более одного** follow-up.
- Ошибки отправки ретраятся (до 3 попыток), «протухшие» записи (старше 7 дней)
  удаляются без отправки.
- 🧪 Кнопка **«Тест»** — посмотреть пример сообщения в своём Telegram.
- Сообщения отправляются штатным методом Кардинала (помечаются как сообщения бота —
  автоответчик на них не срабатывает, в логах чата видны как ваши).

## Установка

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-PostDeliveryBonus/main/post_delivery_bonus.py -O plugins/post_delivery_bonus.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

Команда **`/bonus`** (или `⚙️ Настройки` на странице плагина):

| Кнопка | Действие |
|---|---|
| 🟢/🔴 Включено | Включить/выключить follow-up сообщения |
| ⏱ Задержка: 60 мин. | Через сколько минут после выдачи отправлять (5–4320) |
| 📝 Текст сообщения | Редактировать шаблон ($username, $lot, $order) |
| 🧪 Тест (отправить себе) | Прислать пример сообщения вам в Telegram |

В меню видно, сколько сообщений сейчас в очереди.

### Шаблон по умолчанию

```
Здравствуйте, $username! 👋
Спасибо за покупку лота «$lot»!
Если всё в порядке — буду очень рад вашему отзыву о заказе #$order.
Если возникли вопросы или что-то не так — напишите мне в этот чат, обязательно помогу!

🎁 Постоянным покупателям — скидка 5% на следующий заказ. Просто напишите «постоянный» :)
```

> Совет: скидку в шаблоне можно убрать или поменять — текст полностью ваш.
> В связке с [FPC-RegularsDetector](https://github.com/yungspiderq/FPC-RegularsDetector)
> вы увидите, когда покупатель напишет «постоянный» — и сколько раз он уже покупал.

## Важно знать

- Follow-up отправляется только после **успешной автовыдачи** (событие POST_DELIVERY
  с флагом delivered). На ручные продажи без автовыдачи не срабатывает.
- Очередь привязана к номерам заказов — дубли исключены.
- Настройки и очередь: `storage/plugins/post_delivery_bonus/settings.json`.
